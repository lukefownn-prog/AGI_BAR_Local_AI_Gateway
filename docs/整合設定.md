# 外部工具 / AI 客戶端串接設定

> 對應規畫書第 10 節。

所有客戶端共用同一組資訊：

| 項目 | 值 |
|---|---|
| Base URL | `http://<AI主機IP>:8787/v1` |
| API Key | 每位人員自己的 `agi-bar-xxxxxxxx` |
| 模型名稱 | `agi-bar-default`（或 `agi-bar-fast` / `agi-bar-long`） |

**模型名稱是別名，不是後端真實模型。** Gateway 會依管理員為該人員設定的
Model Routing Chain 自動選擇後端；使用者不需要、也看不到實際模型名稱。

先用 `curl` 確認 Key 可用，再去設定工具：

```bash
curl http://192.168.1.100:8787/v1/models -H "Authorization: Bearer agi-bar-你的Key"
```

## Cursor

程式開發 IDE，透過 AGI BAR API 使用本地模型。

1. `Settings` → `Models` → `OpenAI API Key`
2. 勾選 **Override OpenAI Base URL**，填入 `http://<AI主機IP>:8787/v1`
3. API Key 欄位填入 `agi-bar-xxxxxxxx`
4. 在自訂模型清單新增 `agi-bar-default`，並停用其他雲端模型
5. 按 **Verify** 確認連線

> Cursor 的部分功能（Tab 補全、Composer 的某些模式）走 Cursor 自家伺服器，
> 不會經過 AGI BAR。需要完全本地化時，請只使用 Chat 並確認上述覆寫已生效。

## Claude Code

CLI / Agent 開發工具，由可配置 Endpoint 或相容代理層接入。

```bash
export ANTHROPIC_BASE_URL="http://192.168.1.100:8787/v1"
export ANTHROPIC_AUTH_TOKEN="agi-bar-你的Key"
export ANTHROPIC_MODEL="agi-bar-default"
```

> **注意：** Claude Code 使用的是 Anthropic Messages API 格式，與 OpenAI 格式並不相同。
> AGI BAR V1.2 提供的是 **OpenAI 相容** 端點，因此需要一層 Anthropic ↔ OpenAI 的轉換代理
> （如 `claude-code-router` 一類的相容層）指向 AGI BAR，或等待後續版本內建
> `/v1/messages` 端點。此項列為 M11 的實機驗證項目。

## Codex / OpenAI CLI 系工具

OpenAI 官方與相容 CLI 通常讀取這兩個環境變數：

```bash
export OPENAI_BASE_URL="http://192.168.1.100:8787/v1"
export OPENAI_API_KEY="agi-bar-你的Key"
```

部分版本使用 `OPENAI_API_BASE`（舊名）。若工具支援設定檔，例如：

```toml
# ~/.codex/config.toml
model = "agi-bar-default"
model_provider = "agibar"

[model_providers.agibar]
name = "AGI BAR"
base_url = "http://192.168.1.100:8787/v1"
env_key = "OPENAI_API_KEY"
```

各家 CLI 的欄位名稱差異大，請以該工具當下版本的文件為準。

## DeepSeek（外部雲端備援）

DeepSeek 在 AGI BAR 中的定位是**管理員可選的備援路由**，不是預設模型。

啟用步驟：

1. 於 AI 主機設定環境變數（**不要**寫進 `config.json`）：
   ```
   setx DEEPSEEK_API_KEY "sk-你的DeepSeek金鑰"
   ```
2. 編輯 `config/config.json`，把 `cloud-deepseek` 的 `enabled` 改為 `true`
3. 重新啟動服務
4. 在「AI 模型」頁確認狀態為線上
5. 只把它加入**特定人員**的 Model Route 末位，作為本地模型全數離線時的備援

> ⚠ 啟用外部模型等同同意將該路由的 Prompt 送出本機網路。
> 規畫書原則是「本地開源模型優先」，未經授權不得把內部 Prompt 或程式碼送往外部。
> AGI BAR 對標記 `requiresExplicitConsent` 的模型會在未啟用時直接拒絕請求。

## 自製 App（iOS / Android / Windows / Web）

任何 HTTP 客戶端都能直接呼叫：

```js
const res = await fetch('http://192.168.1.100:8787/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    Authorization: 'Bearer agi-bar-你的Key',
  },
  body: JSON.stringify({
    model: 'agi-bar-default',
    messages: [{ role: 'user', content: '你好' }],
    stream: true,
  }),
});
```

Web App 從瀏覽器直接呼叫時會遇到 CORS。請把該網頁的來源加入
`config/config.json` 的 `security.allowedOrigins`：

```json
{ "security": { "allowedOrigins": ["http://192.168.1.50:3000"] } }
```

> 行動 App 請勿把 API Key 硬編在前端。建議由自家後端代為呼叫，
> 或為每位使用者配發個別 Key 並提供撤銷機制。

## 其他 OpenAI 相容客戶端

只要能自訂 Base URL 與 API Key 即可，例如 Open WebUI、LibreChat、Chatbox、
Continue.dev、LangChain 的 `ChatOpenAI`、LlamaIndex 的 `OpenAILike`。

AGI BAR 目前實作的端點：

| 端點 | 說明 |
|---|---|
| `GET /v1/models` | 模型清單（一般人員只看到別名） |
| `GET /v1/models/:id` | 單一模型 |
| `POST /v1/chat/completions` | 對話，支援 `stream: true` |
| `POST /v1/completions` | 舊版文字補全（內部轉為 chat） |
| `GET /v1/me` | 查詢自身額度與用量 |
| `POST /v1/tools/web_search` | 受控搜尋（需授權上網） |
| `POST /v1/tools/url_fetch` | 受控網頁擷取（需授權上網） |

尚未實作：`/v1/embeddings`、`/v1/images`、`/v1/audio`、Function Calling 的完整轉譯。
用到這些功能的客戶端會收到 `404 unknown_endpoint`。

## 錯誤代碼對照

客戶端收到的錯誤都是 OpenAI 格式，`error.code` 可據以判斷原因：

| code | HTTP | 意義 |
|---|---|---|
| `missing_api_key` | 401 | 沒帶 Authorization |
| `invalid_api_key` | 401 | Key 不存在或已刪除 |
| `key_inactive` | 403 | Key 被暫停或撤銷 |
| `user_inactive` | 403 | 人員帳號被停用 |
| `expired` / `not_yet_valid` | 403 | 超出有效日期 |
| `outside_time_window` | 403 | 不在允許時段 |
| `weekday_not_allowed` | 403 | 今天不在允許星期 |
| `rate_limit_exceeded` | 429 | 超過 RPM |
| `concurrency_limit` | 429 | 超過同時請求數 |
| `quota_exceeded` | 429 | Token 配額用盡（Hard 政策） |
| `request_too_large` | 413 | 單次請求超過上限 |
| `queue_full` / `queue_timeout` | 503 / 504 | 佇列滿載或等待逾時 |
| `all_models_unavailable` | 503 | 路由中的模型全數不可用 |
| `internet_not_allowed` | 403 | 此 Key 未授權上網 |
| `private_network_blocked` | 403 | 目標指向內網位址 |
