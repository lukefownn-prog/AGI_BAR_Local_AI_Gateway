## ⚠ 破壞性變更 / Breaking change / 破壊的変更

**移除受控上網（Web Search / URL Fetch）整組功能。** AGI BAR 回歸單純的網關職責：
驗證、配額、排隊、路由、紀錄。

**The entire controlled-browsing feature (web search / URL fetch) has been removed.**
AGI BAR returns to being purely a gateway: authentication, quotas, queueing, routing, logging.

**制御付き Web アクセス（Web Search / URL Fetch）機能一式を削除しました。**
AGI BAR はゲートウェイ本来の役割に立ち返ります。

移除的端點 / Removed endpoints / 削除されたエンドポイント：

- `POST /v1/tools/web_search`
- `POST /v1/tools/url_fetch`
- `GET` / `PATCH /api/internet`、`POST /api/internet/test`、`GET /api/logs/web`

同時移除管理台的「網路」頁、儀表板的「Internet 狀態」卡、新增人員與配額設定的
「允許上網」欄位，以及設定檔的 `internet` 區塊。

**保留管理台的存取隔離** —— `security.adminAccess` 維持原樣，預設只有 AI 主機本機能開管理台。
**Admin access isolation is retained** — `security.adminAccess` is unchanged.
**管理コンソールのアクセス隔離は維持されます** —— `security.adminAccess` は変更ありません。

## 新增 / Added / 追加

**網頁介面多語系（繁體中文 / English / 日本語）**
管理台、登入頁與網頁聊天都有語言下拉選單。首次進站依瀏覽器語言自動判斷，選過後記住。
切換語言不重新載入頁面，聊天頁已送出的對話會保留。

**Web UI localisation (Traditional Chinese / English / Japanese)**
A language dropdown on the admin console, sign-in page and web chat. The language is guessed from
the browser on first visit and remembered thereafter. Switching does not reload the page, and the
chat conversation is preserved.

**Web UI の多言語化（繁体字中国語 / English / 日本語）**
管理コンソール、ログインページ、Web チャットに言語ドロップダウンを追加しました。

**紀錄保留期同時套用到資料庫**
`logging.retentionDays`（預設 30 天）過去只清 `data/logs/` 的日誌檔，現在也清資料庫中的
`usage_logs` / `request_logs` / `audit_logs`。設 0 或負數為永久保留。

**Log retention now applies to database records too**
`logging.retentionDays` (30 days by default) used to prune only log files; it now also purges
`usage_logs` / `request_logs` / `audit_logs`. Set it to 0 or a negative number to keep forever.

**ログ保持期間をデータベースの記録にも適用**
`logging.retentionDays`（既定 30 日）はログファイルのみが対象でしたが、データベース内の
記録も削除対象になりました。0 または負数で永久保持です。

## 安裝 / Installation / インストール

1. 下載 `AGI-BAR-v2.0.0-win64.zip` 並核對 SHA-256（附件 `.sha256`）
   Download the ZIP and verify its SHA-256 against the attached `.sha256`
   ZIP をダウンロードし、添付の `.sha256` で SHA-256 を照合

   ```powershell
   Get-FileHash .\AGI-BAR-v2.0.0-win64.zip -Algorithm SHA256
   ```

2. 解壓到固定路徑（避開 `Program Files`，會有寫入權限問題）
   Unzip to a fixed path (avoid `Program Files` — write permissions become a problem)
   固定パスへ展開（`Program Files` は書き込み権限の問題が出るため避ける）

3. 需要 **Node.js 24 LTS 以上**，或把 `node.exe` 放進 `runtime\`
   Requires **Node.js 24 LTS or newer**, or place a `node.exe` into `runtime\`
   **Node.js 24 LTS 以上**が必要。または `runtime\` に `node.exe` を配置

4. 執行 `啟動 AGI BAR.cmd`，登入後**立即於「設定」頁修改預設密碼**
   Run `啟動 AGI BAR.cmd`, then **change the default password on the Settings page immediately**
   `啟動 AGI BAR.cmd` を実行し、**ただちに「設定」ページでパスワードを変更**

### 從 v1.2.0 升級 / Upgrading from v1.2.0 / v1.2.0 からの更新

**保留既有的 `config/`、`data/` 與 `models/`，不要覆蓋。**
**Keep your existing `config/`, `data/` and `models/` — do not overwrite them.**
**既存の `config/`、`data/`、`models/` は保持し、上書きしないでください。**

資料庫**不需要手動遷移** —— 被移除的欄位都有預設值，舊資料庫可直接使用。
設定檔中殘留的 `internet` 區塊不會造成錯誤，程式已不再讀取，可自行刪除。

**No manual database migration is needed** — the removed columns all have defaults, so an existing
database works as-is. A leftover `internet` block in the config file causes no error; it is simply
no longer read and can be deleted.

**データベースの手動移行は不要です** —— 削除された列にはすべて既定値があります。設定ファイルに
残った `internet` ブロックはエラーになりません（読まれなくなっただけ）。削除して構いません。

## 注意 / Note / 注意事項

本系統設計為**內部網路**使用，未內建 TLS 終結或 WAF。對外開放前請置於反向代理之後並啟用 HTTPS。
管理台預設僅限 AI 主機本機存取。

This system is designed for **internal networks**; it has no built-in TLS termination or WAF. Put
it behind a reverse proxy with HTTPS before exposing it externally. The admin console is
loopback-only by default.

本システムは**社内ネットワーク**での利用を前提としており、TLS 終端や WAF は内蔵していません。
外部公開時はリバースプロキシの背後に置き HTTPS を有効にしてください。
